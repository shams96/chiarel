# CHIAREL logo files: The House of Clarity lockup

Rendered from the vector masters in `claudedocs/brand/logo-pack-v2/` (wordmark in Libre Bodoni Bold with option D
spacing: +6% tracking, +25 units on A-R and R-E; monogram traced from the owner's artwork supplied 2026-10-29).
The descriptor line "THE HOUSE OF CLARITY(TM)" replaces the supplied "BEAUTY IN RITUAL" line.
Transparent PNG, 2500 px wide. For print and foil use the vector masters, not these PNGs.
`chiarel-header-*-v2.png` and `chiarel-intro-house-ink-v2.png` are the trimmed web sizes used by the site.

- `chiarel-lockup-house-of-clarity-<colour>.png`: monogram + wordmark + descriptor (stacked).
- `chiarel-wordmark-house-of-clarity-<colour>.png`: wordmark + descriptor (header). Use from about 240 px wide.
