## Decided
`main` requires a pull request and the GitHub Actions job `check` (typecheck, lint, 21 vitest tests, production build with placeholder env) to pass. Admin override is allowed (enforce_admins off), no required reviewers. Work on a branch, open a PR with `gh pr create`, wait for `gh pr checks`, then merge.

**Why:** the owner approved this after the audit showed pushes to main deployed with nothing checking them, and a failed Hostinger build went unnoticed.

## Watch out
do not push to main directly. Merging a PR deploys, so for anything touching checkout, cart or webhooks, test a Stripe test-mode checkout first (needs Docker Postgres running: `docker start chiarel-postgres`; Docker Desktop must be open). After merge, confirm the Hostinger deploy succeeded. Next.js is 15.5.27 (params are Promises). Open follow-ups: Vitest and Tailwind/PostCSS vulnerability upgrades, wider tests, staging. See chiarel-foundation-docs.
