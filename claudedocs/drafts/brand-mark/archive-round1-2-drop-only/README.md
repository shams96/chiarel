# CHIAREL brand mark: drop candidates (draft, 2026-10-24)

Built from the owner's "Pure Droplet (Abstracted)" prompt. Geometry is a sharp-apex teardrop (straight tangents into a circular base), 200 x 240 viewBox. G and F use an SVG mask for the cut; flatten to plain paths in a vector editor before production.

| Candidate | Idea | 16 px (true pixels) | Verdict |
|---|---|---|---|
| G_tapered_cut | solid drop, one diagonal negative-space cut (hairline to wide) | cut still visible as a thin line | strongest, most distinctive; best icon candidate |
| E_tall_window | tall drop with an offset drop-shaped window | window reads as an outline | cleanest, closest to the rendered object; more generic |
| F_tall_open | E with a slit through the wall (open ring) | slit fuses at 16 and 32 px | the "not closed" idea, fails small sizes |
| (round 1) A closed window, B slit, C crescent, D cut | stubbier proportions | C hairline vanishes; A/B read as generic oil/water drops | dropped |

Lockups with the CHIAREL / ITALIA wordmark (V19 outlined lockup file) sit in `contact_sheet_lockups.png`: mark left of the wordmark and stacked above it both hold.

Not done: trademark/similarity search for a teardrop mark; physical emboss/deboss test; a motion version of the cut for the home intro. The gold wordmark file in V19 is the deeper gold (#9B7B2E) and is low-contrast on Formal Garden and Red Ochre, so the lockup tests recolour it to #E9D79F on dark.
